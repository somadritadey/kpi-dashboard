## 🚀 How to Use This Project
1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```
2. **Open the Report:**
   * Ensure you have **Power BI Desktop** installed (latest version recommended).
   * Open `KPIDashboard.pbix`.
3. **Refresh Data (Optional):**
   * If updating with new data, go to **Transform Data > Data Source Settings** in Power BI Desktop and point the file path to your local dataset.
